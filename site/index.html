The Ethical Foundation

Our Constitutional Refusals

We reject the extractive patterns of modern big tech. These promises are held by automated tests that fail the build if crossed.

  • No streaks or gamification A family is not a game to be scored. You will never see badges, counters, unread dots, or daily guilt. If a parent is quiet for a month, that is a valid, respected state.
  • No nagging notifications At most one quiet suggestion a day, asking if anything is worth bringing back. It can be silenced forever in a single tap.
  • No third-party trackers or ads Zero ad networks, tracking pixels, or data brokers. Your memories are never mined, analyzed for targeting, or shared with third parties.
  • Never held hostage If you ever stop paying for a subscription, you keep the right to read, search, and export everything you saved. Your memories remain yours forever.
  • Complete export sovereignty Download your entire archive anytime as open, versioned JSON and standard lossless media files. Zero proprietary lock-in.
System Design

Built for 50-Year Longevity

How Memtara ensures your children can access their archive in the year 2076.

Hardware Encrypted

On-device encryption backed by iOS Secure Enclave and Android Keystore. Media is encrypted at rest before hitting any network.

Durable Offline Spool

Saving a memory writes immediately to a local disk spool. Never lost on an airplane or in a basement with zero cellular signal.

Pure Domain Core

Hexagonal architecture in Python 3.12 with 93%+ strict coverage. Free from framework rot and ephemeral cloud dependencies.

Private Single-Family Cloud

Runs as a single lightweight container behind automatic Caddy TLS at family.memtara.com or locally on your home network.

Sovereignty in Practice

Run Your Own Server

Deploy your family's encrypted vault container to any Raspberry Pi, home NAS, or VPS in seconds:

docker run -d \ --name memtara \ --restart unless-stopped \ -p 8000:8000 \ -e ANUVRITTI_MEDIA_KEY="base64-encoded-key" \ -v ~/memtara/data:/var/lib/anuvritti/data \ -v ~/memtara/media:/var/lib/anuvritti/media \ ghcr.io/prasantk8/anuvritti:latest
