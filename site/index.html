Our Constitutional Refusals

Most modern apps are designed to harvest your family's attention and exploit your private data. We built Memtara with the opposite commitments:

  • No streaks or gamification: A family is not a game to be scored. You will never see badges, counters, or daily goals.
  • No nagging notifications: We send at most one quiet suggestion a day, and it can be silenced forever in a single tap.
  • No third-party trackers or ads: Zero ad networks, tracking pixels, or data brokers. Your memories are never analyzed for advertising.
  • Never held hostage: If you ever stop paying, you keep the right to read, search, and export everything you saved.
  • Complete export sovereignty: Download your entire archive anytime as open, versioned JSON and standard media files.

    • Engineering for 50-Year Longevity

    Encrypted at Rest

    Every recording and photo is encrypted on device using hardware-backed Secure Enclave / Keystore keys before uploading.

    Durable Offline Spool

    Capture never fails in a basement or on an airplane. The offline spool survives force-quits and replays with strict idempotency.

    Pure Domain Architecture

    Hexagonal core in Python 3.12 with 93%+ strict coverage and zero framework dependencies in the business layer.

    Private Family Cloud

    Runs as a single container behind automatic Caddy TLS at family.memtara.com or entirely within your home LAN.

    Run Your Own Family Server

    You can run the server on a home Raspberry Pi, NAS, or private VPS in thirty seconds:

    docker run -d --name memtara -p 8000:8000 \
      -e ANUVRITTI_MEDIA_KEY="your-base64-key" \
      -v ~/memtara/data:/var/lib/anuvritti/data \
      ghcr.io/prasantk8/anuvritti:latest
